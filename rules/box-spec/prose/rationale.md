## Основание

Контракт первичен (API First): интерфейс — договор сторон, и дешевле
согласовать его до кода, чем менять после — изменение размазывается по всем
потребителям. Спецификация машиночитаема (OpenAPI — https://spec.openapis.org,
AsyncAPI — https://www.asyncapi.com), поэтому она же служит источником
документации (`spec → docs → code`: один источник не расходится сам с собой)
и осью SemVer-совместимости (см. `release`). Маркер `x-frozen` превращает
«не ломай потребителя» из пожелания в проверяемый факт. Спек-центричная
разработка — индустриальный консенсус (GitHub Spec Kit, spectral, oasdiff;
обзор — research.md, §11).
